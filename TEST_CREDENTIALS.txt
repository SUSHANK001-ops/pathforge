================================================================
 DATABASE RESET (restore fresh demo data)
================================================================
  Run in an Administrator PowerShell:

    $sqlcmd = "C:\Program Files\Microsoft SQL Server\Client SDK\ODBC\170\Tools\Binn\SQLCMD.EXE"
    & $sqlcmd -S ".\SQLEXPRESS01" -E -C -Q "ALTER DATABASE PathForgeDB SET SINGLE_USER WITH ROLLBACK IMMEDIATE; DROP DATABASE PathForgeDB;"

  Then run the app normally:
    cd D:\pathforge
    dotnet run

  The app will recreate the database, apply migrations, and
  re-seed all 12 accounts and all demo content automatically.

================================================================
 DATABASE START (if service is stopped after a restart)
================================================================
  Open PowerShell as Administrator and run:
    net start 'MSSQL$SQLEXPRESS01'

  To make it auto-start on every boot (run once):
    Set-Service 'MSSQL$SQLEXPRESS01' -StartupType Automatic
