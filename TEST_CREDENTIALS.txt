================================================================
 DATABASE RESET (restore fresh demo data)
================================================================
  The database is a single SQLite file: PathForgeDB.db

  To reset to fresh demo data, run in PowerShell:

    cd D:\pathforge
    Get-Process dotnet | Stop-Process -Force -ErrorAction SilentlyContinue
    Remove-Item PathForgeDB.db* -Force
    dotnet run

  The app recreates the database, applies migrations, and
  re-seeds all 12 accounts and all demo content automatically.

================================================================
 DATABASE — NO SERVER TO START
================================================================
  PathForge uses SQLite (a local file), so there is NO database
  service to start after a laptop restart. Just run:

    cd D:\pathforge
    dotnet run

  Your data persists in PathForgeDB.db across restarts.

================================================================
 NOTES
================================================================
  - Passwords stored as BCrypt hashes — never plain text.
  - Database: SQLite file "PathForgeDB.db" (auto-created).
  - No database server, service, or admin rights needed.
